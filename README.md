# 🎬 VideoVerse

**VideoVerse** is a browser-based video editing application designed to make video creation simple, creative, and accessible.

With a modern editing interface, interactive timeline, media importing, audio controls, scene creation, and video export, VideoVerse brings essential video editing tools together in one place.

### ✨ Features
- 🎞️ Video and image importing
- 🎵 Audio importing and playback
- ✂️ Clip splitting, deleting, and rearranging
- 📝 Text and caption scenes
- 🎨 Scene transitions and animations
- ⏱️ Interactive timeline with zoom
- ↩️ Undo and redo
- 📹 Video recording and export

### 🖥️ Platforms
- Standalone HTML application
- Windows EXE port
- Android APK version
